# Dennis Shop

Damn, this thing is clean. No fluff, no fake promises, no 12-step signup. Just two subscriptions, honest prices, and a chat link that actually goes somewhere.

**Live:** https://ningyizhu0.github.io/etalase-subscription/

## What the hell is this?

A dead-simple subscription storefront for **Dennis Shop**. Spotify and iCloud, that's it. No fluff, no ghost links, no fake testimonials, no "AI Powered" nonsense. It's a catalog, a price list, and a "tanya paket" button that actually goes to WhatsApp.

## Stack

- Plain HTML and CSS.
- Zero JavaScript.
- Zero build steps.
- Google Fonts only for the actual fonts.

## Design vibe

Warm paper background, ink black, one burnt-orange accent. Headings in Instrument Serif, body in Bricolage Grotesque. Prices use tabular numerals so they line up like a real printed price sheet. Everything else is restraint: no gradients, no glow, no glass, no bento grid, no fake bands, no fake stats. If it isn't real, it isn't there.

## Anti-slop

- No fabricated stats.
- No fake testimonials.
- No dead nav links.
- No generic CTAs.
- No em dashes.
- No over-filtered, sterile default.

If you want to know why every decision was made, read `DESIGN.md`.
